About this data

Every number on this dashboard comes from Uniqode — no estimates, no stale snapshots.

Scan counts

  • Each physical scan is counted once (Uniqode's webhook sends duplicate events; they are deduplicated).
  • Bot scans (flagged by Uniqode as automated traffic) are included by default, so totals match the Uniqode dashboard exactly. Use the "Bot scans" pill to exclude them and see real human engagement only.
  • Days are bucketed in Pacific time, matching the Uniqode dashboard.
  • Per-day history begins June 4, 2025. All-time totals are exact from each code's creation.

Locations

  • Solid markers sit at exact coordinates stored in the code's Uniqode Metadata (lat, lon, optional address) — human-confirmed.
  • Dashed amber markers are approximate — placed from the code's name (state/city/park) so nothing is invisible. Click one to confirm its exact location; that writes the coordinates into Uniqode and the marker turns solid.
  • Codes whose names couldn't be placed at all are listed under Needs Location Verification with a manual entry form.

Trust check

On every sync, each code's computed total is reconciled against Uniqode's official all-time count. The status dot at the bottom of the map turns amber if any code drifts by more than 2 scans.

Unmapped codes — verify location

These codes have no map position yet (their names couldn't be auto-placed). Add a lat/lon or an address to put each on the map. Saving writes the location into that code's Uniqode metadata.
